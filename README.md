# MuseoDeLosMuseos
Aplicación movil nativa desarrollada como proyecto semestral para la asignautra "Desarrollo de aplicaciones mobiles"

**Museo de los Museos** es una plataforma interactiva que permite a visitantes, investigadores y administradores explorar el patrimonio cultural de museos de Iberoamérica a través de recorridos virtuales, mapas georreferenciados y lectura de códigos QR.

cuenta con las siguientes pantallas:

-- Pantalla 1 — Bienvenida
-- Pantalla 2 — Registro de Usuario
-- Pantalla 3 — Autenticación e Inicio de Sesión
-- Pantalla 4 — Dashboard Principal
-- Pantalla 5 — Mapa de Museos Virtuales
-- Pantalla 6 — Detalle del Museo Virtual
-- Pantalla 7 — Escáner QR 
-- Pantalla 8 — Resultado QR
